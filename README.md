# Comprendre la Renaissance italienne

Prototype de site statique consacré à la Renaissance italienne.

## Publication avec GitHub Pages

1. Créer un dépôt GitHub (par exemple `renaissance-italienne`).
2. Déposer tout le contenu de ce dossier à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche **main** et le dossier **/(root)**, puis enregistrer.
6. GitHub affichera ensuite l'adresse publique du site.

Le fichier d'entrée est `index.html`. Le fichier `.nojekyll` indique que ce site est un site HTML statique simple.

## Structure

- `index.html` : accueil et fiche Fra Angelico
- `assets/images/` : reproductions actuellement utilisées
- `CREDITS.md` : tableau à compléter avant diffusion publique définitive
